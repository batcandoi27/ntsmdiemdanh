# Plan: Class Management System (CRUD & Data Control)
Created: 2026-01-31 22:50:00
Status: 🟡 In Progress

## Overview
Develop a comprehensive Class Management system allowing administrators to perform CRUD operations on Classes and Students directly within the application. This includes viewing class details, editing class info, adding/removing students, and a system-wide "Reset Data" function. This feature empowers users to manage school data visually without relying solely on Excel imports.

## Tech Stack
- Frontend: Next.js (App Router), Tailwind CSS, Lucide React (Icons)
- Backend: Next.js Server Actions
- Database: Firestore (NoSQL)
